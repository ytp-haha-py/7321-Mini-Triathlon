# 七三二十一・七股小三鐵

走、騎、划整合體驗原型。

## 功能

- 走：小隊資料、出發照、彩鹽瓶、散步紀錄。
- 騎：路線總覽、五站自由切換、出發檢查、漁港故事與觀察、四步蚵殼手作；龍山基本線與六孔選配延伸。
- 划：雙人練習、濕地生態解謎、遊覽潟湖的濕地碎片搜集與景觀拼圖、拍照與文字紀錄。
- 三段集章、下載原型完賽證書。

## 騎乘段 Demo

- 黑底、萊姆綠沿用既有視覺；五站持續顯示，目前站點放大。
- 漁港觀察與社區手作完成後收集漁村章，不要求完成出發站或延伸。
- 五站可直接預覽；魚塭只提供可略過的短故事，不設掃碼、答題或照片關卡。
- 作品示意與參考照片可加入範例紀錄，也可自行拍照／選照片；騎乘活動不強制拍照。
- 騎乘故事可使用裝置朗讀；不支援時仍可閱讀全文。語音依裝置而異，可能需要連線，不是錄製的在地導覽。
- 材料包、據點、租還車、接駁及水域服務仍待確認，不提供實際預約或付款。

開啟首頁 → 騎 → 路線總覽 → 漁港觀察 → 社區手作 → 漁村卡。魚塭與六孔可自由預覽；使用說明中可重設本機進度。
