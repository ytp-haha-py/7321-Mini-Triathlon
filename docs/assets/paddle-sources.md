# 划行段生態內容來源

## 六孔碼頭旁的活動案例

台江國家公園管理處〈體驗低碳水域遊憩 巡禮七股潟湖風貌〉，2025 年活動公告：
https://www.tjnp.gov.tw/ch/titlelist/latest-news/2285

公告列明六孔遊憩區碼頭旁七股潟湖水域，並描述定置漁網、蚵架及濕地景觀。文內另有延期公告；不是本專案活動的核准文件，也不能保證本專案路線當天可見相同景物。

## 潟湖環境、生物與漁業的關係

台江國家公園管理處〈「分分合合」－七股潟湖・沙洲〉：
https://www.tjnp.gov.tw/ch/titlelist/feature-stories/2304

文章說明沙洲阻擋外海風浪、潟湖提供魚蝦貝類棲息與繁殖環境，並與養蚵及漁撈相連。App 的三題教學與概念圖依此整理；圖解不是航線、風浪模擬或當日生物調查。

## 體驗設計

「找現場線索 → 掃碼、解謎與解說 → 搜集濕地碎片 → 照片或文字紀錄」是本專案設計。三片碎片代表沙洲、潟湖棲地與漁業三個教學主題，不代表已確認三個實體站點。遊覽、觀察與收集同步進行；沒有看見景物或答錯仍可繼續，不能為了任務靠近漁具或追逐生物。

以上內容於 2026-10-14 查核。預計使用六孔碼頭旁水域；路線、合作業者、活動與設施程序須另行確認。

潟湖景觀拼圖將既有 AI 生成情境圖片切成三片，隨搜集進度逐步顯示。這是景觀遊戲示意，不是七股潟湖測繪圖或實際站點位置。
